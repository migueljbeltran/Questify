# Questify — Gamified Chore App

Questify is a full-stack productivity and chore-tracking web app built with Next.js, TypeScript, Supabase, and the Google Calendar API.

## Features
- User authentication (Supabase)
- Create and complete chores
- Points and gamification mechanics
- Real-time updates
- Google Calendar integration
- Clean, responsive UI

## Tech Stack
- Frontend: Next.js, TypeScript, TailwindCSS
- Backend: Supabase (PostgreSQL), Next.js API Routes
- Integrations: Google Calendar API
- Deployment: Vercel

## How to Run

    git clone https://github.com/YOUR_USERNAME/questify
    cd questify
    npm install
    npm run dev

## Environment Variables Needed
- SUPABASE_URL
- SUPABASE_ANON_KEY
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- NEXTAUTH_SECRET
